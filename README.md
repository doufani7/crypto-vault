## 📖 Description

Welcome to **Crypto Vault** — a secure vault that holds a secret flag.  
Your mission is to find a way inside and retrieve the flag.  
The vault is protected by modern web technologies, but every lock has a weakness.  
Can you find it?

This challenge is designed to test your skills in **web security** and **client-side analysis**.  
Inspect the code, understand the authentication mechanism, and break in.
